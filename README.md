설치할 것도, 명령어를 칠 일도 없습니다. 파일을 고치고 올리면 그게 곧 배포입니다.

## 2. 작품 추가하기

### 1단계 — 그림 파일을 `images/` 폴더에 넣습니다

파일 이름은 영문·숫자·하이픈만 쓰세요. 한글이나 띄어쓰기가 들어가면 일부 환경에서 이미지가 안 뜹니다.

```
좋음:  1ho-001.jpg,  archive-012.jpg
나쁨:  1호 그림(최종).jpg
```

### 2단계 — `assets/data.js`를 열어 목록에 추가합니다

메모장이 아니라 **VS Code** 같은 편집기를 쓰시면 실수한 곳을 빨간 줄로 알려줘서 훨씬 편합니다.

1호 작품이라면 `1ho` 항목의 `artworks: [` 아래에 한 줄씩 추가합니다.

```js
artworks: [
  { image: "images/1ho-001.jpg" },
  { image: "images/1ho-002.jpg", orientation: "landscape" },
  { image: "images/1ho-003.jpg", description: "고요한 수면 위로 빛이 내려앉는 순간입니다." },
],
```

적을 수 있는 값:

| 항목 | 설명 | 생략하면 |
|---|---|---|
| `image` | 이미지 경로 (필수) | — |
| `title` | 작품 제목 | `Canvas 1호 - 001` 처럼 자동 번호 |
| `orientation` | `"portrait"`(세로) / `"landscape"`(가로) | 세로 |
| `size` | 크기 | 갤러리 기본값 |
| `medium` | 재료 | 갤러리 기본값 |
| `price` | 가격 (숫자만, 쉼표 없이) | 갤러리 기본값 |
| `sold` | `true`면 품절 딱지 | 품절 아님 |
| `description` | 작품 설명 | "작품 설명을 준비하고 있습니다." |
| `soldDate` | 판매일 (아카이브용) | 표시 안 함 |

### 3단계 — 저장하고 새로고침

끝입니다. 페이지 수, 총 작품 수, 페이지 번호는 전부 자동으로 계산됩니다.

### 판매된 작품을 아카이브로 옮기려면

`galleries`의 `artworks`에서 해당 줄을 잘라내어 `archive`의 `artworks`로 옮기고,
`soldDate`를 적어주면 됩니다.

## 4. 이미지 준비 요령

이전 사이트가 느렸던 가장 큰 이유가 이미지였습니다. PNG 한 장이 1.5MB씩, 297장이라 총 460MB였습니다.

- **형식은 JPG** (또는 WebP). 그림 사진에 PNG는 용량만 커집니다.
- **가로 최대 1600px** 정도면 충분합니다.
- **한 장당 300KB 이하**를 목표로 하세요.

변환은 [squoosh.app](https://squoosh.app) 에서 파일을 끌어다 놓으면 무료로 됩니다.
품질(Quality)은 80 정도면 눈으로 차이를 느끼기 어렵습니다.

공유 미리보기 이미지로 `images/og-cover.jpg` (1200×630)를 하나 넣어두시면
카카오톡이나 SNS에 링크를 붙일 때 대표 이미지가 나옵니다.

도메인(www.brushjab.com)은 기존 연결을 그대로 쓰시면 됩니다.

## 6. 문제가 생겼을 때

**화면이 하얗게 나온다**
→ `assets/data.js`의 쉼표(`,`)나 따옴표(`"`) 실수가 거의 전부입니다.
브라우저에서 `F12` → `Console` 탭을 열면 몇 번째 줄이 문제인지 알려줍니다.

**그림 자리에 "이미지를 불러오지 못했습니다"가 뜬다**
→ `data.js`에 적은 경로와 실제 파일 이름이 다릅니다. 대소문자와 확장자(`.jpg`/`.png`)를 확인하세요.

**작품을 추가했는데 안 보인다**
→ 브라우저 캐시입니다. `Ctrl+Shift+R` (맥은 `Cmd+Shift+R`)로 강력 새로고침 하세요.
